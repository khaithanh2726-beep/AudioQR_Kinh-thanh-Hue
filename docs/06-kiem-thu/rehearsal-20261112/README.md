# Nguồn kiểm bảo quản bản tập dượt

Lượt 12/11 bảo quản văn bản và MP3 Ngọ Môn sang môi trường riêng, giữ Hash và kiểm nghe thử; kết quả ban đầu tách với lần áp dụng/HTTPS sau đó. Tổng hợp kết quả hiện hành tại [báo cáo kiểm thử](../README.md).

[Hồ sơ nguyên bản tại mốc lưu mã nguồn](https://github.com/khaithanh2726-beep/AudioQR_Kinh-thanh-Hue/blob/601c09acd34e45d3d0b17bf2b7dbe94daf6bdae1/docs/06-kiem-thu/rehearsal-20261112/README.md). Log/JSON/ảnh đầy đủ được bảo quản trong hồ sơ kiểm thử riêng, giữ nguyên Hash. Đường dẫn này được giữ để hồ sơ Ngọ Môn đã duyệt tiếp tục tra được nguồn.
